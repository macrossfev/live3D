# 样品 A1 — UV 重绘路线

## 做法
- 保留 RPM 人头几何 `Wolf3D_Head`（2123 顶点，含鼻/耳形状）
- 页内把每个 UV 三角形按其**世界位置分区**填色：前脸银 / 下颚红 / 侧后红
- 眼睛在 UV 上找眼心最近顶点位置画杏仁椭圆（亮黄 `#fff6c0`），纯贴图无发光几何
- 贴图经 `CanvasTexture` 回贴（1024²，glTF UV 习惯手动翻转）

## 怎么跑
```
python3 -m http.server 8099
# 打开 http://localhost:8099/tools/rpm_ultraman.html?head=a1
```

## 已知瑕疵（事实陈述）
1. **鼻子/耳朵的几何形状仍在**——侧视（left.png/right.png）可见人鼻轮廓从银面凸出，这是本路线的先天风险，请侧图重点裁决
2. 眼睛是平面贴图，无发光、无凸起；侧看无立体感
3. 头顶无冠脊几何（贴图路线无法加体积）；头顶纹未画
4. 面料分区按世界位置一刀切，下颚红边界为水平线，非立绘曲线
5. 身体蒙皮与 A2 完全同源（共用管线），腰盆/大腿偏暗的问题两包相同，不作为头路线差异项
