# 样品 A2 — 几何替换路线

## 做法
- 隐藏 `Wolf3D_Head`，用独立头盔替换
- 头盔由 `tools/gen_helmet_a2.py`（Blender 无头，椭球组合法）生成：
  颅球/后脑/扁脸/下颚/下巴/矢状冠脊(薄刃)/眉骨 椭球拼合 + 面级分区（前脸银/侧后红/下颚红）
  + 独立杏仁眼凸起（发光黄，无穿透眼窝）+ 圆柱耳板
- 产物 `assets/output/helmet_a2.glb`（2598 顶点，0 非流形，包络 x±0.107 v-0.137..0.121 d±0.13 米）
- 页面 `?head=a2` 把 GLB 挂到 Head 骨世界位置（worldToLocal 平移），随头动
- 首版曾用 Skin 修改器：分支斜接不可控（下巴垂/头顶扁），已弃；缩放轴序坑已修

## 怎么跑
```
blender -b -P tools/gen_helmet_a2.py     # 重建 GLB
python3 -m http.server 8099              # 打开 ?head=a2
```

## 已知瑕疵（事实陈述）
1. **头盔前脸分区疑反**：正面渲染头部偏红（Blender 分区判据 `c.y<-.03` 的轴序在导出后待核）——如选本路线，一行修正重导
2. 眼位固定在头盔坐标 (±.046, .004, .094)，未按立绘眼高锚点二次校准
3. 冠脊为薄椭球刃，顶部高出颅顶约 3mm，无立绘上的"小鳍"放大
4. 头盔与颈部衔接处（下缘）可能与躯干穿插，侧视可见接缝
5. 身体蒙皮与 A1 同源，腰盆/大腿偏暗不作为头路线差异项
