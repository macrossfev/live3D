## 换算成头盔几何参数（生成器用）

- 颅：半宽 0.1135 / 半高 0.0875 / 半深 0.095，中心 (0, .01, -.01)
- 眼：两枚 r=.035 椭球 scale(1.05,.45,.45)，位 (±.038, .005, .093)，z 旋 ±0.26 上挑——**不是小点，是灯罩**
- 冠脊：前后薄刃 scale(.09,.22,1.15) @ (0,.095,-.02)，前端起于额、后到脑后
- 下颚红区：头盔下部 35%（y< -.045 且前脸）
- 耳：r .015 薄圆柱 ±.108
